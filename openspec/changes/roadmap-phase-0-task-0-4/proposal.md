## Why

A well-organized directory structure is essential for maintainability and scalability. This establishes the foundation for the detector modules, analyzers, utilities, and test/sample files.

## What Changes

- Create `src/` directory for source code
- Create `src/detectors/` for pattern detection modules
- Create `src/analyzers/` for statistical analysis modules
- Create `src/utils/` for shared utilities
- Ensure `tests/` directory exists
- Create `samples/` directory for test texts

## Capabilities

### New Capabilities

### Modified Capabilities

None - this is foundational structure.
