## Context

Test samples are needed to validate the detector. AI-generated samples should contain typical AI writing patterns (vocabulary, structure), while human-written samples should show natural variation and authenticity.

## Goals / Non-Goals

**Goals:**

- Create 3-5 AI-generated sample texts
- Create 3-5 human-written sample texts
- Cover diverse topics (technology, science, history, etc.)

**Non-Goals:**

- Creating a comprehensive test suite
- Generating samples programmatically

## Decisions

### Sample Topics

- AI-generated: Technology trends, digital transformation, data analysis
- Human-written: Personal essays, journalism excerpts, academic writing

### File Format

Plain text files (.txt) for easy reading and processing.

## Risks / Trade-offs

| Risk                              | Mitigation                           |
| --------------------------------- | ------------------------------------ |
| Samples may not be representative | Include variety of topics and styles |
