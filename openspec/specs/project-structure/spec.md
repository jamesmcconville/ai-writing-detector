## Requirements
### Requirement: Source directory exists

The project SHALL have a `src/` directory containing all TypeScript source code.

#### Scenario: Source directory exists

- **WHEN** the project structure is examined
- **THEN** the `src/` directory exists at the project root

### Requirement: Detectors directory exists

The project SHALL have a `src/detectors/` directory for pattern detection modules.

#### Scenario: Detectors directory exists

- **WHEN** the project structure is examined
- **THEN** the `src/detectors/` directory exists

### Requirement: Analyzers directory exists

The project SHALL have a `src/analyzers/` directory for statistical analysis modules.

#### Scenario: Analyzers directory exists

- **WHEN** the project structure is examined
- **THEN** the `src/analyzers/` directory exists

### Requirement: Utils directory exists

The project SHALL have a `src/utils/` directory for shared utility functions.

#### Scenario: Utils directory exists

- **WHEN** the project structure is examined
- **THEN** the `src/utils/` directory exists

### Requirement: Tests directory exists

The project SHALL have a `tests/` directory for test files.

- **THEN** the `tests/` directory exists

### Requirement: Samples directory exists

#### Scenario: Samples directory exists

- **THEN** the `samples/` directory exists
